Guía rápida de instalación y ejecución en red local.

Requisitos

  • Node.js (recomendado >= 16) y npm instalados.
  • Windows / macOS / Linux.
  • Acceso a la red local (Wi‑Fi/Ethernet) para uso en LAN.

Instalación

$ npm install

Ejecución local (producción)

$ npm start $ node server.js

Por defecto usa el puerto 3000. Para cambiar el puerto en Windows (PowerShell):

PS> $env:PORT=8080; node server.js

Ejecución en red local (LAN)

  1. Arranca el servidor. En la consola verás la(s) URL(s) disponibles, por ejemplo:
http://localhost:3000
http://192.168.1.12:3000

Exponer públicamente (opcional)

  1. Usa una herramienta como ngrok para exponer tu servidor local a Internet.
$ npx ngrok http 3000

Cómo modificar la información de inicio de sesión del docente

Las credenciales de usuarios se almacenan en el archivo data/users.json.

Ruta del archivo: data/users.json

Ejemplo de estructura (actual)

{
  "users": [
    {
      "id": "usr_001",
      "username": "Docente",
      "password": "Docente2026",
      "displayName": "Docente",
      "role": "docente",
      "avatar": "👩‍🏫",
      "createdAt": "2024-01-15"
    }
  ],
  "roles": { /* ... */ }
}

Para modificar las credenciales del docente:

  1. Abre data/users.json en un editor de texto.
  2. Localiza el objeto con "role": "docente".
  3. Cambia los campos username, password y/o displayName.
  4. Guarda y reinicia el servidor.

Ejemplo — cambiar usuario y contraseña

{
  "id": "usr_001",
  "username": "prof_garcia",
  "password": "docente2024",
  "displayName": "Prof. García",
  "role": "docente",
  "avatar": "👩‍🏫",
  "createdAt": "2024-01-15"
}

Después de guardar los cambios, el nuevo usuario docente será:

  • Usuario: prof_garcia
  • Contraseña: docente2024

Recuerda reiniciar el servidor para que los cambios surtan efecto.
